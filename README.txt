Данные и скрипт для отрисовки всех фигур статьи
=================================================

Структура (не менять, пути жёстко зашиты в qedlib.py):

    make_all_figs.py                          -- главный скрипт
    qedlib.py                                 -- загрузчик данных
    work/qedfci_frozen_cs+z_with_opt/         -- сканы H2 и LiH (fig1-5,8,9)
    work/qedfci_atom/                         -- данные по гелию (fig6,7)
    cc_lambda_scan/                           -- QED-HF/CCSD по H2, Sadlej
    fci_lambda_scan/                          -- QED-FCI по H2, Sadlej
                                                  (вместе дают fig_cc_vs_fci)

Запуск:

    python make_all_figs.py

Результат появится в новой папке figs2/ -- 10 фигур, каждая в .eps
(основной формат), .pdf и .png (для просмотра).

Легенды на всех фигурах непрозрачные (framealpha=1.0) -- можно свободно
двигать их руками в векторном редакторе поверх линий графика.
